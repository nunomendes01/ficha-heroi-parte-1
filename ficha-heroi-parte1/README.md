# decisões de UI/UX

# hierarquia visual

o nome do herói e os títulos das seções tem um maior destaque

# contraste

fiz um fundo escuro com texto claro e dourado para ler melhor

# consistência

as seções usam as mesmas cores, espaçamentos e bordas

# proximidade

informações que pertencem do mesmo assunto tão juntas

o inventário usa 3 colunas no desktop, 2 no tablet e 1 no celular, seção do herói e as colunas de atributos se arrumam em telas menores
